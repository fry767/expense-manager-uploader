Privacy policy

This policy covers Expense Manager APK Uploader, a personal utility that uploads signed Android app builds from GitHub Actions to the owner's Google Drive. It covers the uploader and this informational website.

Google data accessed and used

The uploader requests the https://www.googleapis.com/auth/drive.file scope. It accesses only Drive files and folders created by, or explicitly made available to, this OAuth application. Its configured use is to create the Expense Manager APKs folder, upload or replace expense-manager-latest.apk, and read the file's metadata and ID to produce a private download link.

The uploader does not read unrelated Drive documents, contacts, email, or the expense records stored by the installed Android app. It does not request permission to list or access the entire Drive.

Credentials and storage

Google authorization happens in Google's sign-in interface on the owner's computer. The resulting OAuth client configuration and refresh token are stored in a private local configuration and, with the owner's approval, in a GitHub Actions repository secret. GitHub build jobs write a temporary configuration to authenticate the upload and remove that file when the upload finishes.

Android build files are stored as private GitHub Actions artifacts for 30 days and in the owner's Google Drive until removed. Drive may retain earlier revisions according to its own policies. Build summaries and logs may contain the APK's filename and private download link. Authorization credential values are not intentionally printed to logs or included in this website.

Sharing and third-party services

Google provides sign-in and Drive storage; GitHub provides build runners, protected secrets, artifacts, logs, and hosting for this website. Google data is used only to deliver the requested APK to the owner's Drive. The uploader does not change sharing permissions; the owner controls any later sharing through Drive.

Google user data is not sold or used for advertising, profiling, or training machine-learning models. This site has no advertising, analytics scripts, or tracking cookies. GitHub Pages may process ordinary hosting information, such as IP addresses, under the GitHub privacy statement. Google services are subject to the Google privacy policy.

Retention, revocation, and deletion

The owner can stop automated access by revoking the uploader in Google Account connections and removing the GOOGLE_DRIVE_RCLONE_CONFIG GitHub Actions secret and local configuration. Revoking access does not automatically delete previously uploaded APKs. The owner can delete the APK folder and its trash contents in Drive, and remove GitHub artifacts or workflow runs separately.
